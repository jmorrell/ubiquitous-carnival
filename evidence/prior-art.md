## Frontend: three different trust models

**EmDash sandbox plugins return host-rendered declarations.** A finite `block.type` switch renders host React components. Sandboxed admin/editor route results undergo validation with byte/depth/node limits. These declarations can be interactive; the distinction is who supplies the executable UI implementation. A new CAD interaction is not proven expressible by this vocabulary. [Renderer](https://github.com/emdash-cms/emdash/blob/30604dcb0538df477ea0d8bde894ecdb57388bad/packages/blocks/src/renderer.tsx#L21), [validation call site](https://github.com/emdash-cms/emdash/blob/30604dcb0538df477ea0d8bde894ecdb57388bad/packages/core/src/emdash-runtime.ts#L5700), [limits](https://github.com/emdash-cms/emdash/blob/30604dcb0538df477ea0d8bde894ecdb57388bad/packages/blocks/src/validation.ts#L60).

**EmDash native components are trusted build imports.** Generated modules statically import admin modules and public block components. The sandbox proxy deliberately skips `page:fragments`. Native arbitrary components have application trust, rather than browser containment. [Admin imports](https://github.com/emdash-cms/emdash/blob/30604dcb0538df477ea0d8bde894ecdb57388bad/packages/core/src/astro/integration/virtual-modules.ts#L326), [block imports](https://github.com/emdash-cms/emdash/blob/30604dcb0538df477ea0d8bde894ecdb57388bad/packages/core/src/astro/integration/virtual-modules.ts#L456), [sandbox exclusion](https://github.com/emdash-cms/emdash/blob/30604dcb0538df477ea0d8bde894ecdb57388bad/packages/core/src/plugins/sandbox/proxy.ts#L57).

**Cloudflare OS executes arbitrary gadget JavaScript in an iframe.** `srcDoc` receives a MessageChannel/Cap'n Web bootstrap. CSP disallows ordinary remote connections/media, frames and forms while allowing inline/data scripts and data media. Before handing over the RPC port, the parent verifies `event.source` against the actual iframe and `event.origin === 'null'`. This is custom browser code, not a host declaration vocabulary or an import into the host component tree. [Document/CSP](https://github.com/cloudflare/cloudflare-os/blob/8060cd9fde6bdec1159df46054f0a559e93822a1/packages/workshop-frontend/src/GadgetUI.tsx#L105), [bootstrap](https://github.com/cloudflare/cloudflare-os/blob/8060cd9fde6bdec1159df46054f0a559e93822a1/packages/workshop-frontend/src/GadgetUI.tsx#L25), [port authentication](https://github.com/cloudflare/cloudflare-os/blob/8060cd9fde6bdec1159df46054f0a559e93822a1/packages/workshop-frontend/src/GadgetUI.tsx#L340).

**Do not infer zero exfiltration from OS's iframe.** Its flags include popups and popups-to-escape-sandbox. Injected code replaces `window.open`, but deliberately retains user-activated links opening new tabs. A JavaScript monkeypatch is not a containment primitive. Magpie's experiment needs no popup permission. [Popup handling](https://github.com/cloudflare/cloudflare-os/blob/8060cd9fde6bdec1159df46054f0a559e93822a1/packages/workshop-frontend/src/GadgetUI.tsx#L51), [sandbox flags](https://github.com/cloudflare/cloudflare-os/blob/8060cd9fde6bdec1159df46054f0a559e93822a1/packages/workshop-frontend/src/GadgetUI.tsx#L505).

## Backend authority and effects

**EmDash concretely restricts backend authority.** Worker Loader sets `globalOutbound: null`, CPU/subrequest limits, and a bridge with plugin identity, capabilities, allowed hosts and declared storage, rather than passing host Env. The HTTP implementation checks capabilities, URL schemes, internal literal hosts, and the allowlist on every redirect; it strips credentials on cross-origin redirects. This is implemented policy, not a claim that every possible DNS/SSRF strategy was audited. [Runner](https://github.com/emdash-cms/emdash/blob/30604dcb0538df477ea0d8bde894ecdb57388bad/packages/cloudflare/src/sandbox/runner.ts#L357), [HTTP bridge](https://github.com/emdash-cms/emdash/blob/30604dcb0538df477ea0d8bde894ecdb57388bad/packages/cloudflare/src/sandbox/bridge-http.ts#L206).

**Declarations do not automatically imply item scope.** `declaredAccessToCapabilities` lowers `content.read` to `content:read` without compiling nested predicates. `contentGet(collection,id)` and `contentList` check a broad permission and collection syntax, then accept caller-selected identities. Magpie should mint run/item-bound capabilities and validate artifact membership. [Lowering](https://github.com/emdash-cms/emdash/blob/30604dcb0538df477ea0d8bde894ecdb57388bad/packages/plugin-types/src/index.ts#L305), [content bridge](https://github.com/emdash-cms/emdash/blob/30604dcb0538df477ea0d8bde894ecdb57388bad/packages/cloudflare/src/sandbox/bridge.ts#L935).

**User actions have a separate authority boundary.** EmDash saved-entry dispatch requires a private route, authorizes the caller, reloads the persisted entry, checks ownership permissions, and creates canonical item/version context. A processing grant alone cannot authorize a browser annotation mutation. [Dispatcher](https://github.com/emdash-cms/emdash/blob/30604dcb0538df477ea0d8bde894ecdb57388bad/packages/core/src/plugins/http-route-dispatch.ts#L199), [context](https://github.com/emdash-cms/emdash/blob/30604dcb0538df477ea0d8bde894ecdb57388bad/packages/core/src/plugins/http-route-dispatch.ts#L333).

**Cloudflare OS supplies resource-capability examples.** Its loader disables ambient egress, passes only selected named bindings, and checks gatekeeper opening with an approval queue. `GitHubIssueImpl` retains `logicalId`; `setTitle(title)` queues an action against that identity. The caller supplies neither credentials nor a replacement repository URL. `createIssue` returns a provisional object after queuing approval. Borrow the narrow bound-object pattern, without adopting the whole approval/simulation platform. [Loader](https://github.com/cloudflare/cloudflare-os/blob/8060cd9fde6bdec1159df46054f0a559e93822a1/packages/workshop-backend/src/overseer.ts#L4494), [selected env](https://github.com/cloudflare/cloudflare-os/blob/8060cd9fde6bdec1159df46054f0a559e93822a1/packages/workshop-backend/src/overseer.ts#L2519), [gatekeeper session](https://github.com/cloudflare/cloudflare-os/blob/8060cd9fde6bdec1159df46054f0a559e93822a1/packages/workshop-backend/src/overseer.ts#L6255), [bound issue](https://github.com/cloudflare/cloudflare-os/blob/8060cd9fde6bdec1159df46054f0a559e93822a1/packages/gatekeeper-github/src/github.ts#L5771), [provisional creation](https://github.com/cloudflare/cloudflare-os/blob/8060cd9fde6bdec1159df46054f0a559e93822a1/packages/gatekeeper-github/src/github.ts#L5609).

**Timeout is not cancellation of effects.** EmDash's wall-time check uses `Promise.race` with completion callbacks still attached to the invocation, separate from actual Loader CPU/subrequest limits. A timed-out invocation may already have dispatched paid work. Magpie needs late-write fencing plus idempotency or reconciliation, rather than an exactly-once claim based on workflow retries. [Timeout implementation](https://github.com/emdash-cms/emdash/blob/30604dcb0538df477ea0d8bde894ecdb57388bad/packages/cloudflare/src/sandbox/runner.ts#L408).

## Implemented, documented, proposed

All paths above are implemented at their pins and were inspected, but the upstream applications were not run here. Broader OS security/simulation claims are documented promises, not established by this review. Independently deployed Gatekeepers are explicitly future work in the [OS README](https://github.com/cloudflare/cloudflare-os/blob/8060cd9fde6bdec1159df46054f0a559e93822a1/README.md#L64). PR270's Magpie adaptation and the present contract are proposals, not EmDash features.

The local frontend experiment compares selecting a transcript segment, seeking media, and proposing an annotation against an artifact revision. A fixed template can do this only if the host supplies that behavior; isolated code should add the local interaction without a new host action. This comparison is tested separately here rather than inferred from upstream source.
