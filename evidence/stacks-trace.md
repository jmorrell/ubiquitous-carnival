The checked-in synthetic http://notebook.example/article fixture makes the path concrete; browser extraction and external responses in this fixture are controlled.

2. **Identity and scheduling.** upsertLibraryItem deduplicates submitted URLs and allocates independent item/capture IDs. A repeated save preserves the capture and returns already-saved while moving the item to the top ([app/src/server/lib/durable-objects/tenant-library/tenant-library.ts:92](https://github.com/jmorrell/stacks/blob/ba2c100d4cca0164cd1752cebaec72b11ba4a016/app/src/server/lib/durable-objects/tenant-library/tenant-library.ts#L92)). 3. **Selection.** The workflow HEAD-follows the URL to get media type unless it has a snapshot ([app/src/server/lib/workflows/save-library-item/save-library-item.ts:79](https://github.com/jmorrell/stacks/blob/ba2c100d4cca0164cd1752cebaec72b11ba4a016/app/src/server/lib/workflows/save-library-item/save-library-item.ts#L79); redirect implementation at line 270). ## Ownership and assumptions outside ContentHandler

- **Useful but incomplete ownership split.** User status/star/read-count/tags belong to the stable item; generated details and artifacts belong to the capture. A unique index enforces one capture per item ([app/src/server/lib/durable-objects/tenant-library/tenant-library.sql:61](https://github.com/jmorrell/stacks/blob/ba2c100d4cca0164cd1752cebaec72b11ba4a016/app/src/server/lib/durable-objects/tenant-library/tenant-library.sql#L61) and line 149). The original belongs to the same deletable capture as derivatives.
- **Destructive refresh.** Before processing, refresh queues all old artifacts for deletion, deletes artifact rows/details/capture, then creates a new processing capture ([app/src/server/lib/durable-objects/tenant-library/tenant-library.ts:136](https://github.com/jmorrell/stacks/blob/ba2c100d4cca0164cd1752cebaec72b11ba4a016/app/src/server/lib/durable-objects/tenant-library/tenant-library.ts#L136)). On refresh failure, prior readable/search output and original bytes are already unavailable. Stable item flags/tags survive; slug/artifact IDs do not. Refresh is outside the current experiment.
- **Original is a name, not immutability.** Captured input and processor-produced original share that name. Workflow lines 159–165 can overwrite captured bytes if the handler returns different content.
- **Type widening is insufficient.** HTML/PDF is hardcoded in handler unions, metadata, public response, internal capture type and SQL CHECK. URL is required and unique. Reserved readable/image names constrain joins, image rewriting and UI. Search returns item-level results only.
- **Existing video is shallow.** YouTube fetches oEmbed, generates HTML with a remote iframe, indexes only title, and archives neither media nor transcripts ([app/src/server/lib/content-fetch/content-handlers/websites/youtube-handler.ts:69](https://github.com/jmorrell/stacks/blob/ba2c100d4cca0164cd1752cebaec72b11ba4a016/app/src/server/lib/content-fetch/content-handlers/websites/youtube-handler.ts#L69)). Reader sanitization does not add iframe to allowed tags. The apparent embed/sanitizer mismatch is source-derived, not browser-verified.
- **Existing PDF preserves bytes only.** It buffers the full download using arrayBuffer(), emits no search text and produces no readable artifact ([app/src/server/lib/content-fetch/content-handlers/pdf-handler.ts:11](https://github.com/jmorrell/stacks/blob/ba2c100d4cca0164cd1752cebaec72b11ba4a016/app/src/server/lib/content-fetch/content-handlers/pdf-handler.ts#L11)).
- **Idempotency is scoped.** Artifact-key reuse and stale-capture guards do not prove exactly-once paid work. Image description checks for a stored description, invokes AI, then stores it: a crash can occur in that gap ([app/src/server/lib/durable-objects/tenant-library/tenant-library.ts:895](https://github.com/jmorrell/stacks/blob/ba2c100d4cca0164cd1752cebaec72b11ba4a016/app/src/server/lib/durable-objects/tenant-library/tenant-library.ts#L895)).

## Consequences that earn contract concepts

1. Archive input separately from processor output. The host assigns IDs and retains original bytes.
2. Publish a finite manifest of artifact references and selected search text. Validate references before commit. Existing artifact storage supports this direction more strongly than one returned byte array or opaque metadata.
3. Services need host-enforced authority. The prototype uses a concrete synthetic transcription service; paid-effect recovery is deferred.
4. Preserve a host-readable fallback, then independently test the smallest isolated detail-code boundary needed for synchronized media.
5. Existing API authentication is a useful outer boundary; untrusted plugins need narrower item/object authority than Env.
